# Great Falls Tool Bus: paths that stay off upstream.
#
# Agent tooling lives on contributor forks, named <repo>-contrib, on the
# agents-overlay branch. It never lands on an organization branch or in a pull
# request into one. The rule is CONTRIBUTING.md, section "Agents":
# https://github.com/Great-Falls-Tool-Bus/.github/blob/main/CONTRIBUTING.md
#
# Canonical copy: meta steering/githooks/. Mirror: the organization .github
# repository, githooks/. Repositories vendor it in .githooks/ with the hooks.
# The pre-push hook reads it for pushes to an organization remote. In meta,
# `just upstream-tooling-audit` reads it for every default branch or for one
# pull request.
#
# Syntax, one entry per line:
#   deny PATTERN                       a path that must not be upstream
#   deny REPO:PATTERN                  the same, for one repository only
#   keep PATTERN                       never flagged, whatever matches it
#   allow REPO:PATH TICKET REASON      one tracked file admitted on purpose
#
# A PATTERN is anchored at the repository root. `*` and `?` stay inside one
# path segment. A leading `**/` lets the rest start at any depth. A trailing
# `/` covers everything below that directory. Matching is by path, never by a
# word inside a path or a file. Every allow entry names a ticket and a reason.
