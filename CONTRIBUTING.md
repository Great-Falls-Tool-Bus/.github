# Contributing

Great Falls Tool Bus is a member-run club. To get involved, see
[greatfallstoolbus.org/wants](https://greatfallstoolbus.org/wants) or reach
us at [greatfallstoolbus.org/contact](https://greatfallstoolbus.org/contact).

## Source access

Our source repositories are private. Access is granted by an org owner.

## Working here

- Contributors enable two-factor authentication, upload an SSH key, and
  sign their commits.
- Work happens on branches, through pull requests, with review before
  merge.
- Where a repository has a Justfile, `just` is the only entrypoint —
  don't call the underlying tools directly.
- Org members receive the private onboarding guide from an owner once
  access is granted.

## Commits

Commit as yourself. Don't add AI-attribution trailers (e.g.
`Co-Authored-By`) to commits or pull requests.
